🧠 TaskTrack — Feature-Rich To-Do Manager

TaskTrack is a modern, responsive, feature-rich To-Do Manager built using HTML, CSS, and Vanilla JavaScript.
It helps users efficiently manage tasks with priorities, due dates, filters, and local storage support.

✨ Features

➕ Add, edit, and delete tasks

✅ Mark tasks as completed

⚠️ Automatic Overdue detection

🔍 Search tasks by title

🎯 Filter by Priority and Status

🔃 Sort tasks (date, title, due date)

📊 Live Task Summary Dashboard

💾 Data saved using LocalStorage

📁 Export tasks to CSV

📱 Fully Responsive UI

🛠️ Tech Stack

HTML5

CSS3 (Modern UI, gradients, responsive layout)

JavaScript (ES6)

LocalStorage API
